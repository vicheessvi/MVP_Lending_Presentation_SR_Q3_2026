# SmartRoom — итоги Q3 2026

Интерактивная презентация на русском языке. HTML, CSS и JavaScript находятся в одном файле. Внешние библиотеки, шрифты и сетевые зависимости отсутствуют.

## Запуск

Скачайте репозиторий и откройте `index.html` в Chrome, Edge или Firefox. Установка и сборка не требуются.

## Слайды

1. SmartRoom: объёмная сфера SR, входящие потоки данных и таймер сбора участников на 15 минут.
2. Инициативы МЦТП по улучшению качества и точности в АС SmartRoom: четыре инициативы, Q1–Q4 и итоговый тренд.
3. Разработка SmartRoom и выполнение бизнес требований: результаты Q1–Q3, планы Q4 и статус устранения багов.
4. Разработка SmartRoom и выполнение доработок: результаты Q3, планы Q4, просроченные доработки с причинами и эффекты реализации.
5. Пожелания и зоны улучшения SmartRoom: причины, примеры и факты, предложения.
6. Вопросы и обсуждение с объёмной анимацией.

Числовые показатели и часть тезисов содержат явно обозначенные поля для заполнения. До выступления внесите фактические данные.

## Управление

| Действие | Управление |
| --- | --- |
| Переключение слайдов | Кнопки, стрелки, Page Up / Page Down, пробел |
| Выбор слайда | Цифры 1–6 |
| Первый / последний слайд | Home / End |
| Полный экран | F или кнопка вверху |
| Пауза анимаций | M или кнопка вверху |
| Запуск / пауза таймера | T на первом слайде или кнопка под сферой |
| Скрытие / показ таймера | Кнопка с часами на первом слайде |

Таймер не сбрасывается при переходе между слайдами или скрытии. Скрытие не приостанавливает отсчёт. Перезагрузка страницы начинает новую сессию.

## Редактирование

1. Нажмите **«Тезисы»** и измените текст в пунктирных полях.
2. На четвёртом слайде используйте **«+ Добавить эффект»** и крестики для изменения списка эффектов.
3. Нажмите **«Сохранить HTML»**. Браузер скачает автономный `SmartRoom-edited.html` с изменениями.

Изменения до скачивания существуют только в открытой вкладке. Чтобы обновить версию в репозитории, замените `index.html` содержимым сохранённого файла и создайте коммит.

На узких экранах рабочие слайды прокручиваются. Системное предпочтение уменьшенного движения учитывается автоматически.
